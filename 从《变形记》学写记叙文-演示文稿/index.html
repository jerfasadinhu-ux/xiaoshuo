从《变形记》学写记叙文

话题五探究成果分享

《促织》与《变形记》比较阅读

先读三句话

他若想收回一条腿，这条腿却向外伸得笔直；要是他成功地利用这条腿随心所欲地动作，其他腿就像被释放似的，极其痛苦地乱踢乱蹬起来。
一种棕色的液体从嘴巴里流了出来，从钥匙上滴落到地上。
"现在我得起床了，要赶五点的火车呢。"

一个人变成了虫子，为什么读起来像真的？

今天练三招

  1. 写具体过程，别写结论
  2. 让人物各说各话，别让所有人喊一样的话
  3. 用日常想法写重大时刻

实践一

写具体过程，别写结论

卡夫卡怎么写"变成虫"

✗ 他变成了虫，非常痛苦。
✓ 他若想收回一条腿，这条腿却向外伸得笔直；要是他成功地利用这条腿随心所欲地动作，其他腿就像被释放似的，极其痛苦地乱踢乱蹬起来。

不写"痛苦"两个字，而是让你亲眼看到他翻身翻不了的全过程。

场景：考试考砸了

✗ 成绩出来了，我考得很差，非常难过，心里像压了一块石头。
✓ 卷子是倒扣着发下来的。我掀开一角，看见了一个"4"。我用拇指盖住十位数，不想看，但手指已经在发抖了。周围同学在互相问分数，我赶紧把卷子塞进桌肚，假装在找笔。

"考得很差"是结论。"掀开一角""手指发抖""塞进桌肚"是过程。过程比结论有力量。

动手写：一次迟到的经历

要求：不准出现"着急""紧张""慌张"等情绪词。只能写动作、看到的、听到的。150字以上。

提示：闹钟显示几点？穿衣服哪只袖子卡住了？楼下什么气味？冲进教室时老师在说什么？

参考示例

闹钟显示七点二十三。我盯着它看了三秒，被子掀到一半就停住了。校服裤子在地上，我一把捞起来，左脚塞进去，右脚踩到了裤脚，一个踉跄撞在床角上，膝盖传来一阵钝痛，没空管它。书包昨天没收，课本散了一桌，我把它们一股脑往里塞，有一本怎么都塞不进去——是数学练习册，卷角了。楼下飘上来煎蛋的味道，妈妈在喊"快来吃"，我没应。推开门的时候楼道里很凉，拖鞋还穿在脚上。折回去换鞋，鞋带系成死结，用指甲抠了两下抠不开，干脆塞进鞋帮里。跑到小区门口，7路公交车正关上门开走了。我站在站牌下面，书包带子勒得肩膀疼，低头一看——左脚白球鞋，右脚黑运动鞋。

全文没有一个"着急"或"紧张"，但读者全程都替你急。

实践二

人物各说各话，别让所有人喊一样的话

格里高尔变虫后，家人的反应

人物说的/做的背后的逻辑
母亲"他不舒服，请你相信我"替儿子掩饰
父亲拿手杖和报纸赶他保护家庭体面
妹妹"你不舒服？你需要什么？"不愿面对，假装正常
协理"这是动物的声音"，跑了陌生人：恐惧+逃跑

越是亲近的人，越不肯面对真相。每个人的反应都符合"他是谁"。

场景：宣布不想高考了

✗ 妈妈大惊失色："你说什么！"爸爸拍桌子："胡闹！"奶奶也急了："这怎么行！"
✓ 妈妈手里的筷子停在半空，看了我一眼，又低头夹菜，说："先吃饭。"
爸爸没吭声，放下碗去阳台抽烟了。
奶奶凑过来小声说："是不是学习压力太大了？奶奶给你炖点汤。"

三个人都没反对，但反应完全不同：妈妈假装没听见、爸爸沉默、奶奶用关心绕开。

动手写：家庭聚餐宣布决定

题目：家庭聚餐时，你宣布了一个重要决定（转学、学艺术、放弃竞赛等）。

要求：至少三个家庭成员的不同反应，必须符合身份和性格。不准让所有人说"不行"或"你疯了"。200字以上。

参考示例

"我想转去学美术。"我说完这句话，饭桌上安静了大概五秒钟。外婆第一个开口："你画画不是挺好的嘛，小时候还得过奖呢。"她说这话的时候还在给我夹菜，好像我说的不是转学，是明天想吃什么。爸爸把酒杯放下，没看我，转头问妈妈："你们单位那个老周的女儿，是不是也学的美术？"妈妈愣了一下，说："嗯……好像是。"爸爸点点头，没再说话，但筷子一直没动。表姐从手机上抬起头，冲我眨了一下眼，小声说："回头加个微信，我认识一个画室的老师。"只有爷爷什么也没说，饭后他出去遛弯的时候路过我房间，门口停了一下，咳了一声，走了。

五个人，五种反应——外婆用回忆回避、爸爸用打听消化、表姐偷偷支持、爷爷沉默但在意。

实践三

用日常想法写重大时刻

变成了虫，想的是什么？

✗ 他变成了虫，绝望地哭了。
✓ "要是我能多睡一会儿，把所有这些倒霉的事儿都丢在脑后，那该多好啊。"
"现在我得起床了，要赶五点的火车呢。"

人生中最离奇的事发生了，他脑子里想的是——担心迟到。这种反差比"他崩溃了"有力一百倍。

场景：毕业，最后一次回望校门

✗ 我站在校门口，心中涌起无限感慨。三年的时光啊，就这样结束了。我的眼眶湿润了，青春真的回不去了。
✓ 我站在校门口，回头看了一眼教学楼。三楼最左边那扇窗户，是我们班的，窗帘还歪着，跟三年前一样。我突然想起来，储物柜里还有一盒没吃完的饼干，忘了拿了。算了。

"忘了拿饼干"——在这种时刻想这种小事，反而让读者觉得酸楚。这就是反差的力量。

动手写：一个"告别"的场景

题目：写一个"告别"的场景（毕业、搬家、分手、送别等）。

要求：不准写"不舍""感慨""泪流满面"等抒情文字。只写这个时刻脑子里冒出来的琐碎念头。150字以上。

提示：注意到了什么平时不会注意的细节？有没有冒出一件完全无关的小事？声音、温度、光线？

参考示例

爸爸把最后一个箱子搬上车，拍了拍手上的灰，说"走吧"。我站在单元门口，没动。六月的太阳已经很强了，地上的影子缩成小小的一团。三楼阳台上，妈妈的拖鞋还晾在那里，一只是红的，一只是蓝的——她穿错了一年，也没发现。楼下小卖部的阿姨正在把冰柜往里推，冰柜门开着，里面还亮着灯。我想起来，我还有两块钱押在她那儿，存冰棍的。算了，不要了。爸爸按了一下喇叭。我拉开车门，座椅是热的，皮面粘着后背。收音机在放一首老歌，调频台还没换，还是原来那个。车开出去的时候，后视镜里，小卖部的阿姨冲我挥了挥手。

没有"不舍""留恋""泪目"，但"两块钱押金""拖鞋穿错一年""收音机没换台"让离别有了重量。

三条口诀

口诀意思从《变形记》学到的
别写结论，写过程 让读者自己经历 格里高尔翻身翻不了，写了一整段
别让所有人说一样的话 每个人只说自己会说的话 母亲掩饰、父亲驱赶、妹妹假装正常
别写该有的情绪 大事发生时，人想的往往是小事 变成了虫，想的是"要赶五点的火车"
